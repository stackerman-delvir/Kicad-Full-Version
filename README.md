## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Eeschema** — Create detailed electronic schematics with ease.
- **Symbol Editor** — Edit and project schematic symbols tailored to your designs.
- **PCB Editor** — Design and edit printed circuit board layouts with advanced tools.
- **Gerbview** — View and manage documents in the GERBER format for manufacturing.
- **Cvpcb** — Select appropriate footprints for schematic components effortlessly.

### Advanced Features:
- **Footprint Editor** — Customize PCB footprint libraries to meet your project needs.
- **Image Converter** — Convert bitmap images into schematic symbols quickly.
- **Calculator** — Calculate resistance, capacitance, and other electronic parameters.
- **Drawing Sheet Editor** — Design and edit graphic sections for components.
- **3D Viewer** — Visualize your final product with realistic images and integration checks.
